# مصاريفي (Masarifi)

تطبيق ويب قابل للتثبيت على الموبايل لمتابعة الالتزامات الشهرية والمصاريف اليومية، مع تحليل وتوصيات ترشيد.

- الحسابات وقاعدة البيانات: Supabase (كل مستخدم يرى بياناته فقط عبر Row Level Security)
- الاستضافة: GitHub Pages

## التثبيت على الموبايل
- آيفون (Safari): Share ← Add to Home Screen
- أندرويد (Chrome): ⋮ ← Install app
